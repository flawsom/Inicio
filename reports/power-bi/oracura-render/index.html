BACK
The deck's split (21% promoters, 64% passives, 15% detractors, NPS +6) cannot be reproduced from CF14 in the workbook: every aggregation above puts promoters near 105 of 204 and detractors near 21. The deck therefore used a different recommendation cut - a different wave, an overall recommendation question, or pre-cleaning data - while the workbook repeats CF14 per product purchased (CF7-CF16 per product, per the questionnaire routing). The same grain difference explains the smaller gaps: better than expected 59.5% here vs ~66% in the deck, top-2 satisfaction 88.2% vs 90%. Demographics reconcile exactly (all nine cities, gender 56/44, under-35 64%), which confirms both files describe the same 204 respondents. This report stands on the workbook numbers; the deck column is shown so the gap is audited, not hidden.
